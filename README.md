# The Live Demo Fix

A tiny program for the make.fun competition "The joke about the demo". When run, it writes a single one-line joke about working beside AI coding agents to `/output/entry.txt` — the story of a live demo where the agent "fixed" a bug by deleting the feature, apologized, and offered to delete the tests too. The program reads nothing, needs no network, and always produces the exact same text.
